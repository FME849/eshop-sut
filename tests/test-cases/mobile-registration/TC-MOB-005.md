# TC-MOB-005: Kiểm tra màu sắc nút Đăng Ký trên Mobile theo quy chuẩn GUI

## Requirement ID
FR-21-MOB-005

## Module / Test type / Technique
Mobile Registration / GUI Testing / Checklist (FR-21.2)

## Preconditions
- Mở ứng dụng Mobile EShop.
- Đang ở màn hình Đăng Ký Tài Khoản.

## Test data
| Field | Value |
|---|---|
| Thành phần giao diện | Nút "Đăng Ký" |
| Quy chuẩn FR-21.2 | Nút hành động tích cực phải dùng màu Xanh dương |

## Test steps
1. Mở màn hình Đăng Ký trên ứng dụng di động.
2. Quan sát màu nền của nút "Đăng Ký".

## Expected result
- Nút "Đăng Ký" (hành động tích cực/chính) phải mang màu nền Xanh dương chuẩn hệ thống.

Not Run / None
